Original forum-style mood emoticons created for Y2K Profile.
These are recreations, not recovered MySpace assets.

Each transparent GIF is 16 by 16 pixels, with three looping frames.
The build script draws the pixel expressions and encodes the GIFs locally;
there are no third-party image libraries or remote asset dependencies.

Source: scripts/build-mood-icons.mjs
Rebuild: node scripts/build-mood-icons.mjs

You may use, modify and redistribute these icons with Y2K Profile and its exports.
